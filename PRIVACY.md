# Privacy Policy

LinkedIn Job Text Copier does not collect, transmit, sell, or share user data.

The extension runs only on LinkedIn Jobs pages and adds copy buttons to the page. When a user clicks a copy button, the extension reads visible job information from the current page and writes it to the local clipboard.

The extension stores only local extension preferences, such as whether the optional post-apply popup auto-close toggle is enabled.

The extension does not use analytics, remote code, external servers, background network requests, or third-party services.
